# sheetgenius/tap

Homebrew formulae from SheetGenius.

```sh
brew install sheetgenius/tap/<formula>
```

| Formula | What it is |
|---|---|
| [`glowy`](https://github.com/sheetgenius/glowy) | Mermaid diagrams in glow |
| [`mermaid-ascii`](https://github.com/AlexanderGrooff/mermaid-ascii) | Renders Mermaid diagrams as terminal text (upstream release binaries; a dependency of glowy) |
